# Examples

Small, complete programs that compile and run — each one twice, under `go run`
and under go2js + node — with `scripts/smoke.sh` refusing on any difference.
They are the program-side face of the parity rule: what compiles here is what
an ordinary Go program can rely on.

| example | what it shows |
| ------- | ------------- |
| `hello_world` | the smallest program that can be, compile to JS, print to stdout |
| `async_channels` | goroutines, buffered channels, `close` + `range`, `select` with `default`, `time.After` |
| `http_shapes` | `net/http` handlers and `ServeMux` routing answered through `httptest.NewRecorder` — server shapes without a listening socket, so the example ends |
| `realworld` | a tour across the stdlib — `strings`, `bytes`, `strconv`, `sort`, `json`, `regexp`, `os`, `io`, `net/url`, `net/http`, `time`, `sync` — printed section by section |

Each directory holds `main.go`, and `main.js` is the compiled output,
regenerated by `scripts/refresh-examples.sh` so it never drifts from the
source. Run one end to end:

```sh
go run ./examples/http_shapes          # the Go truth
go2js -o out.js examples/http_shapes && node out.js   # the same program compiled
```

To try them all and have a script check them:

```sh
scripts/smoke.sh
```
